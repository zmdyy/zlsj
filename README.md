# 资料收集登记助手

给班级登记用的本地小工具。可以导入名单、按班级分组、登记已交或考试分数，并导出 Excel。

数据写在本文件夹的 `data\store.json` 里。清理浏览器缓存不会把这份文件清掉。

## 打开方式

1. 电脑需要已安装 [Python 3](https://www.python.org/downloads/)。
2. 双击 `启动.bat`。
3. 浏览器会打开 `http://127.0.0.1:8765/`。

`启动.bat` 会在后台启动保存程序，然后打开页面。结束任务管理器中的 Python 进程后，页面就不能再写入文件。换一台没有 Python 的电脑时，请先安装 Python，再双击 `启动.bat`。

也可以直接双击 `index.html`。这样打开时，点右侧「保存」，或关闭页面，都会下载 `资料收集数据.json`（一般在浏览器的下载文件夹）。下次打开后，用「恢复备份」选中这份文件即可继续。若当时保存程序正在运行，关闭页面会直接写入 `data\store.json`，不再另下文件。

## 文件夹

| 文件 | 作用 |
|---|---|
| `启动.bat` | 启动本机保存程序，并打开页面 |
| `server.py` | 把登记数据写入 `data\store.json`，只接受本机访问 |
| `index.html` | 页面结构 |
| `app.js` | 导入、查询、登记、分组、导出 |
| `styles.css` | 页面样式 |
| `vendor\` | 拼音查询和 Excel 读写所需的库 |
| `data\store.json` | 当前名单、分组、登记和分数 |
| `data\store.bak.json` | 上一份自动备份。误覆盖后，可用页面里的「恢复备份」，或手工用这份文件替换 `store.json` |

## 使用

- 导入 Excel、CSV，或直接粘贴名单。姓名后一列如果是班级，导入时会自动分成小组。
- 登记区上方可以按班级查看。统计、导出和批量操作跟随当前选中的班级。
- 新建项目时可选三种登记方式：已交 / 未交、同意 / 不同意、考试分数。名单是共用的，每个项目各自保存状态或分数。
- 关闭页面前，当前内容会自动写入 `data\store.json`。

## 数据说明

`data\store.json` 里主要有两部分：

- `people`：名单。每个人有 `id`、`name`、`group`（班级）、`note`（其他备注）。`id` 是内部编号，不是学号。
- `tasks`：项目。`mode` 为 `binary`（已交/未交）、`three`（同意/不同意）或 `score`（考试分数）。已交状态在 `status`，分数在 `scores`，都用人员 `id` 对应。
